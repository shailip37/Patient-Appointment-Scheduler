# Patient Appointment Scheduler

## Preview

![App Screenshot](appointment-scheduler-screenshot.png)

A full-stack patient appointment scheduling web application built using Node.js, Express.js, JavaScript, HTML, and CSS.

## Features

- Add appointments
- Edit appointments
- Delete appointments
- Dynamic frontend rendering
- REST API backend
- Patient and doctor information tracking

## Technologies Used

- Node.js
- Express.js
- JavaScript
- HTML
- CSS
